🧢 BravesBot
BravesBot is a Discord bot built for Atlanta Braves fans. It responds to the /score command with:

📅 Upcoming Game Info: Displays the next scheduled Braves game with start time.

⚾ Live Game Updates: If a game is currently in progress, it shows the live score and game status (inning, outs, etc).

Key Features:
Slash command: /score

Fetches real-time data for Braves games

Clean, user-friendly message formatting for Discord

Ideal for integrating into sports or Braves-themed Discord servers.
